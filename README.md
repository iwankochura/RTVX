# Yuxia Bio Link

Адаптивная bio-link страница с живыми счётчиками Telegram и TikTok на Cloudflare Workers.

## Локальный запуск

```bash
npm install
npm run dev
```

## Живые счётчики

Worker получает публичные значения со страниц:

- Telegram: `https://t.me/yuxiazx`
- TikTok: `https://www.tiktok.com/@yuxiazxc`

Ответ API кэшируется на 10 минут, чтобы страницы соцсетей не запрашивались при каждом открытии сайта. Если внешний источник временно недоступен, в интерфейсе остаются резервные значения из HTML.

Токены, секреты и отдельная база данных не требуются.

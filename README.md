# RTVX Bio Link

Одностраничный сайт RTVX со ссылками на Spotify, Telegram и TikTok и кнопкой копирования почты. Визуальная палитра взята из фотографии автомобиля: холодный серебристый свет, графит и небольшие красные акценты. Светлая и тёмная темы переключаются кнопкой в шапке; выбор сохраняется в браузере.

## Локальный запуск

```bash
npm install
npm run dev
```

Кнопка «поделиться» копирует текущий адрес страницы. Публичный сайт: https://rtvx.pages.dev/.

## Публикация

Из корня проекта после входа в нужный аккаунт Cloudflare:

```bash
npm run deploy:pages
```

Сайт загружается в Cloudflare Pages напрямую через Wrangler, чтобы включить Pages Function для счётчиков. Репозиторий GitHub хранит исходники, но отправка коммитов туда сама по себе не запускает публикацию.

## Счётчики

Страница запрашивает `/api/stats` при открытии и каждые две минуты. Worker получает публичные значения с `https://t.me/rtvx929` и `https://www.tiktok.com/@somebodyyy14`. Если платформы не возвращают доступные данные, на странице остаётся «—» вместо чужих или устаревших чисел.

Cloudflare Pages Function использует тот же обработчик статистики, что и Worker. Для локальной работы KV не требуется; без него значения запрашиваются у соцсетей при обращении к API. Если позже настроить собственный binding `STATS_KV`, Worker сможет отдавать кэш и обновлять устаревшие значения в фоне. В проекте нет привязки к прежним облачным ресурсам.
